# JSP1020

Java Servlet과 JDBC로 MySQL 데이터를 조회·등록·수정·삭제하는 웹 실습 프로젝트입니다.

- 사원(`emp`), 부서(`dept`), 주문(`orders1`) 데이터 처리
- HTML 폼 입력을 Servlet으로 받아 DB에 반영
